# 日払い 愛知 LP

GitHub Pagesへそのままデプロイできる静的LPです。

## ファイル構成
- `index.html` : LP本体
- `privacy.html` : プライバシーポリシー
- `assets/style.css` : デザイン
- `assets/script.js` : スムーススクロール用JS

## 公開前に必ず変更する箇所
1. `index.html` 内の `https://lin.ee/XXXXXXXX` を実際のLINE URLへ一括置換
2. `privacy.html` の運営事業者名・住所・連絡先を実際の情報へ変更
3. 必要に応じて求人条件・表現を実際の取り扱い求人に合わせて調整

## GitHub Pages
リポジトリ直下へこのフォルダ内のファイルをアップロードし、Settings → Pages から公開してください。
